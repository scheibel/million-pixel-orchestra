# Neue Demo

Diese Vorlage nach `demos/<name>/` kopieren und anpassen. Vollständige Anleitung: `demos/README.md` im Repository.

- **Lernziel:** Was soll verstanden werden?
- **Mathematik:** Welche Formel bestimmt die Farbe?
- **START → ZIEL:** Welche Änderung wird sichtbar?
- **Zwischenstände:** Welche vollständigen, kompilierbaren Schritte helfen beim Live-Coding?

Jede `.glsl`-Datei enthält ein vollständiges ShaderToy-Image-Snippet. Nur `fragCoord`, `iResolution` und bei Bedarf `iTime` nutzen; keine Uniform-Deklarationen oder lokale Viewer-Funktionen übernehmen.
