# Leerer Editor

Diese Vorlage ist ein freier Einstieg für eigene Experimente, keine zusätzliche Live-Demo des Workshops. Die Landingpage verlinkt sie separat oberhalb der sechs vorbereiteten Demos.

`VORLAGE.glsl` enthält ein vollständiges ShaderToy-Snippet. Der konstante RGB-Vektor `vec3(1.0)` färbt alle Pixel weiß. Die Farbberechnung kann direkt im Editor verändert und über „Stand wiederherstellen“ auf die Vorlage zurückgesetzt werden.

Der optionale Eintrag `starter` in `site/catalog.json` registriert die Vorlage unabhängig von der geordneten Workshop-Demoliste. Ihre einzige Stand-ID `ziel` erfüllt den bestehenden Metadatenvertrag; die sichtbare Beschriftung lautet „Vorlage · Weiß“.
