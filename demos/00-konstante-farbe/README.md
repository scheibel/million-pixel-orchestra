# Ein Pixel, eine Farbe

Technische Beispieldemo für das Rahmenwerk, noch keine ausgearbeitete Unterrichtseinheit.

**Kerngedanke:** Ein konstanter RGB-Vektor weist jedem Pixel dieselbe Farbe zu. Die drei vollständigen Shader unterscheiden sich ausschließlich in ihren Farbanteilen: `START.glsl` (Petrol), `01-violett.glsl` und `ZIEL.glsl` (Koralle).

`fragCoord` gehört bereits zur ShaderToy-Schnittstelle, wird hier aber noch nicht verwendet. `iResolution` und `iTime` werden für eine konstante Farbe ebenfalls nicht benötigt. Alle Dateien können vollständig in das Image-Codefeld von ShaderToy kopiert werden.
